The vertical slice of **The House Beyond Midnight**: the Prologue, Chapter One (*The Stopped Clocks*) and Chapter Two (*The Last Waltz*), ending at the Grand Clock's second chime. About 1½–2 hours to play.

### Downloads

| Platform | File | How to run |
| --- | --- | --- |
| Windows 10/11 | `HouseBeyondMidnight-0.3.0-Windows.exe` | Download and double-click. SmartScreen may warn because the game isn't code-signed yet: **More info → Run anyway**. |
| macOS 11+ (Intel and Apple silicon) | `HouseBeyondMidnight-0.3.0-macOS.zip` | Unzip, move the app to Applications, then right-click it and choose **Open** the first time (it isn't notarised yet). |
| Linux (x86_64) | `HouseBeyondMidnight-0.3.0-Linux.x86_64` | `chmod +x HouseBeyondMidnight-0.3.0-Linux.x86_64`, then run it. |
| Android 8+ (64-bit) | `HouseBeyondMidnight-0.3.0-Android.apk` | Open the file on your phone and allow installs from that source. Test build, signed with a debug key. |

Each platform is a single file. The Mac app has to come inside a zip because macOS apps are folders under the hood.

**Needs:** a graphics card with Vulkan support (most from 2016 on), 8 GB RAM, about 5 GB free space. The first launch takes a little while as the house is built.

### What's in it
- **Rooms:** Ashcombe House in a storm, from the drive and entrance hall through the guest wing and a hidden cloakroom to the Grand Ballroom, in the present and on the sealed night of 1891.
- **Tools:** the Gloam Lantern and the Midnight Watch, plus clues, deductions and a three-tier hint system.
- **Characters:** the Night Porter, Pip, the Forgotten Host (a three-part encounter ending in a last dance), and Mara Bell, who becomes playable.
- **Extras:** wardrobe outfits, cheat codes hidden in lantern light, collectibles and achievements.
- **Saves:** three slots, export and import, and short Midnight Codes.

### Known limitations
- The desktop builds include the 2K texture set only, to keep each download under GitHub's 2 GB file limit: the Ultra preset uses 2K textures instead of 4K.
- The builds aren't code-signed or notarised yet, hence the security prompts above.
- This is a slice: ten more chimes are planned. See [the roadmap](https://github.com/sadirhossain0/the-house-beyond-midnight/blob/main/docs/ROADMAP.md).
